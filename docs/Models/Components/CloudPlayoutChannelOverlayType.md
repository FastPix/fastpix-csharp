# CloudPlayoutChannelOverlayType

The kind of overlay. A `static` overlay shows a fixed image or video, and a `dynamic` overlay renders content that changes while it is on air.

This is an open enum: unknown server values are preserved. `IsKnown` is false and `Value` holds the raw string.


## Values

| Name | Value |
| --- | --- |
| `Static` | static |
| `Dynamic` | dynamic |
