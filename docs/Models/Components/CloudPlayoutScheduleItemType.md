# CloudPlayoutScheduleItemType

What plays. `vod` is a media item, `live` is the channel's live input, and `bumper` is a short clip that plays around an item.

Unknown server values are preserved: `IsKnown` is false and `Value` holds the raw string.


## Values

| Name | Value |
| --- | --- |
| `Vod` | vod |
| `Live` | live |
| `Bumper` | bumper |
